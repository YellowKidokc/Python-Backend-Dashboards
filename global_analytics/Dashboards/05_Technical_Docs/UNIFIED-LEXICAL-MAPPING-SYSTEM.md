## STATISTICAL ANALYSIS FORMULAS

### Disambiguation Necessity Score (DNS)
```
DNS = (# traditional meanings) × (max conceptual distance) × (usage frequency) × (1 - overlap_percent/100)

Where:
- # traditional meanings = count of conflicting definitions
- max conceptual distance = 0-10 scale of how different meanings are
- usage frequency = link_count / total vault links
- overlap_percent = highest overlap with any traditional definition

Interpretation:
- DNS > 5.0 = CRITICAL - new definition essential
- DNS 2.5-5.0 = HIGH - new definition strongly recommended
- DNS 1.0-2.5 = MEDIUM - clarification needed
- DNS < 1.0 = LOW - traditional definition acceptable with note
```

### Co-Term Density Calculation
```
co_term_density = (# specialized terms within ±15 words) / total_occurrences × 100

Example:
If "coherence" appears 50 times in vault, and within ±15 words we find:
- "χ" (40 times)
- "field" (35 times)
- "entropy" (30 times)
- "Logos" (28 times)

co_term_density = (40+35+30+28) / 50 × 100 = 266 terms per 100 occurrences
```

### Overlap Percentage Calculation
```
overlap_percent = (shared_concepts / total_concepts) × 100

Method:
1. List 10 core properties of traditional definition
2. List 10 core properties of Theophysics definition
3. Count how many match
4. Calculate percentage

Example: "Coherence"
Traditional (Physics): phase relationship, wave interference, quantum correlation, etc.
Theophysics: some wave properties + Logos alignment + spiritual unity
Overlap: 3/10 = 30%
```

### Python Script: Calculate Co-Term Density

```python
# co_term_density.py
import os
import re
from collections import Counter, defaultdict

def calculate_co_term_density(vault_path, term, window_size=15):
    """
    Scan vault for 'term' and count specialized terms within ±window_size words.
    Returns: co-term density score
    """
    specialized_terms = [
        'χ', 'Logos', 'coherence', 'entropy', 'field', 
        'observer', 'collapse', 'grace', 'pneumatological',
        'actualization', 'Lagrangian', 'Master Equation'
    ]
    
    co_occurrences = Counter()
    term_count = 0
    
    for root, dirs, files in os.walk(vault_path):
        for file in files:
            if file.endswith('.md'):
                filepath = os.path.join(root, file)
                with open(filepath, 'r', encoding='utf-8') as f:
                    content = f.read().lower()
                    words = re.findall(r'\b\w+\b', content)
                    
                    # Find all occurrences of target term
                    for i, word in enumerate(words):
                        if word == term.lower():
                            term_count += 1
                            # Look at ±window_size words
                            start = max(0, i - window_size)
                            end = min(len(words), i + window_size + 1)
                            context = words[start:end]
                            
                            # Count specialized terms in context
                            for spec_term in specialized_terms:
                                co_occurrences[spec_term] += context.count(spec_term.lower())
    
    if term_count == 0:
        return 0
    
    total_co_terms = sum(co_occurrences.values())
    density = (total_co_terms / term_count) * 100
    
    return {
        'term': term,
        'occurrences': term_count,
        'co_term_density': round(density, 2),
        'top_co_terms': co_occurrences.most_common(5)
    }

# Usage:

print(f"Term: {result['term']}")
print(f"Occurrences: {result['occurrences']}")
print(f"Co-Term Density: {result['co_term_density']}")
print(f"Top Co-Terms: {result['top_co_terms']}")
```

```python
# overlap_percent.py
def calculate_overlap(traditional_props, theophysics_props):
    """
    Compare two sets of defining properties.
    Returns: overlap percentage
    """
    shared = set(traditional_props) & set(theophysics_props)
    total = len(set(traditional_props) | set(theophysics_props))
    
    if total == 0:
        return 0
    
    overlap = (len(shared) / total) * 100
    return round(overlap, 1)

# Example usage:
```

```python
# disambiguation_necessity_score.py
def calculate_dns(num_meanings, conceptual_distance, usage_freq, overlap_percent):
    """
    Calculate Disambiguation Necessity Score.
    
    Args:
        num_meanings: Number of conflicting traditional definitions
        conceptual_distance: 0-10 scale of how different they are
        usage_freq: 0-1 normalized usage frequency in vault
        overlap_percent: Highest overlap with any traditional definition
    
    Returns:
        DNS score (higher = more critical need for new definition)
    """
    dns = num_meanings * conceptual_distance * usage_freq * (1 - overlap_percent/100)
    return round(dns, 2)

# Example: "Coherence"
dns_coherence = calculate_dns(
    num_meanings=3,          # Physics, Theology, Philosophy
    conceptual_distance=8,   # Very different meanings
    usage_freq=0.85,         # Used a LOT in vault
    overlap_percent=30       # Only 30% overlap
)

    num_meanings=2,          # Physics, Spiritual

    usage_freq=0.65,         # Used fairly often
    overlap_percent=45       # 45% overlap
)
```
