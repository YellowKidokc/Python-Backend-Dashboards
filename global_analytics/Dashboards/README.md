# 03_Docs - Documentation

This directory contains all documentation for the Theophysics project, organized into logical subdirectories.

## Directory Structure

*   **/01_Templates**: Contains various templates for notes and documents.
*   **/02_Wizards**: Contains "wizard" scripts or documents designed to guide specific processes.
*   **/03_Concepts**: Contains markdown files detailing individual concepts, atoms, molecules, and foundational ideas.
*   **/04_Prompts**: Contains prompts and prompt-related documentation.
*   **/05_Technical_Docs**: Contains technical specifications, architecture diagrams, migration protocols, and system overviews.
*   **/06_Dashboards**: Contains markdown files for various dashboards.
*   **/07_Indices**: Contains index files for different categories, such as concept hubs, tags, and series.
*   **/08_Papers**: Contains individual articles, papers, and longer-form documents.
*   **/Concept_Hubs**: Automatically generated concept hub pages.
*   **/MOCs**: Automatically generated Maps of Content.

## Usage

Navigate through the subdirectories to find specific types of documentation. The index files in `07_Indices` can help in navigating concepts and tags.
