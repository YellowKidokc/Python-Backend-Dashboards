# Tab 2: Axiom Manager

**Purpose**: Manages foundational assumptions and rules. Tracks axioms, their supporting evidence, contradictions, and coherence scores.

**Group**: Discovery & Analysis  
**Priority**: Phase 2

---

## Overview

This tab displays all axioms in the vault, organized by theory, with tools for detecting contradictions, tracking evidence, and managing coherence.

---

## Core Functions

### 1. Axiom Registry
- List all axioms with UUID, text, theory, coherence score
- Sort by theory, coherence, or date added
- Filter by status (healthy, conflicting, unsupported)

### 2. Contradiction Detection
- Automatically flag axioms that conflict
- Show detailed analysis of each conflict
- Suggest resolutions
- Calculate coherence impact

### 3. Evidence Linkage
- Show which evidence supports each axiom
- Track support strength
- Identify unsupported axioms
- Visualize support chains

### 4. Coherence Scoring
- Per-axiom coherence score
- Contribution to global coherence
- Historical tracking
- Trend analysis
